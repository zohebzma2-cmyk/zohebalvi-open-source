# Zoheb Alvi — Open Source

Free, openly-licensed **3D-printable designs** and **web templates**. No paywall, no signup — clone it, print it, ship it.

These were previously sold; they're now open source. Featured at **[zohebalvi.com/#open-source](https://zohebalvi.com/#open-source)**.

## 🧰 3D-printable designs — `3d-print-designs/`  *(CC-BY-4.0)*

Parametric where noted; print flat, no supports. Designed on a FlashForge Adventurer 3.

| Design | What's inside |
|---|---|
| `coilcap-cable-system` | **67-part modular cable storage system** (MIT). 5 box widths × 3 heights, slide-in printed labels, dovetailed baseplates, wall mounts, drawer trays — all from one parametric source, plus the build and assembly-test harness that verifies them |
| `cordcase-capsule-system` | **57-part upright capsule system** (MIT). Sealed stand-up case per cable — fluted body, contrasting snap-on cap, spine label — 5 footprints × 3 heights, plus a local configurator that generates and verifies any size on demand |
| `socket-system-complete` | The full kit — dovetail wall rails (1/4, 3/8, 1/2", metric + SAE), labeled hex-bit holder, DeWalt ToughSystem Gridfinity drawer set + baseplate, fit-test coupons |
| `dovetail-socket-rails` | Six interlocking socket rails, friction-post grip, embossed sizes, keyhole wall mounts |
| `gridfinity-drawer-set` | Gridfinity baseplate + socket bins sized to the DeWalt ToughSystem 2.0 drawer (42 mm spec) |
| `labeled-hex-bit-holder` | 16 labeled hex pockets, dovetails onto the rails |
| `gridfinity-bin-set` | 1×1 / 2×1 / 2×2 / 1×3 bins with dividers + label ledge + parametric source |
| `desk-cable-organizer-pack` | Cable comb, under-desk headphone hook, phone stand with pass-through |
| `workshop-pegboard-pack` | Pegboard hook + bin, headphone stand, interlocking drawer divider |
| `desk-setup-pack` | Earbuds stand, wall key + mail organizer, desk-edge cable drop clip |
| `workspace-pack` | Phone charging dock, wall tool/marker rack, modular monitor-riser leg |

## 🌐 Web templates — `web-templates/`  *(MIT)*

Pure HTML + CSS. No build step, no dependencies. Three color themes each + a customization guide.

| Template | What it is |
|---|---|
| `aurora-portfolio` | Fast, modern one-page portfolio |
| `nova-saas-landing` | Dark SaaS/product landing — hero, features, pricing, CTA |
| `luma-link-in-bio` | One-page link-in-bio / personal links |
| `halo-coming-soon` | Coming-soon / waitlist landing with email capture |
| `sheet-resume` | Print-ready one-page resume/CV |
| `ledger-invoice` | Print-ready invoice with auto-computed totals |
| `tiers-pricing` | Pricing page with monthly/annual toggle |
