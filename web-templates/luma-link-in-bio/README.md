# Luma — Link-in-Bio Template
A one-page personal links / link-in-bio page. One file, no build, no dependencies.
## Included
- `index.html` + 3 themes: purple, sunset, ocean
## Customize
1. Pick a theme (or edit the `--brand` vars).
2. Edit the `LINKS` and `SOCIALS` arrays in the script + your name/bio/avatar initials.
3. Deploy to any static host. That's it.
