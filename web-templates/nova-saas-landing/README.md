# Nova — Dark SaaS Landing Page Template
Fast, responsive single-page SaaS/product landing. No build, no dependencies (HTML + CSS, Google Fonts via CDN).
## Included
- `index.html` + 3 themes: `index-blue.html`, `index-magenta.html`, `index-teal.html`
## Customize
1. Pick a theme (or edit the four `--brand`/`--glow` vars in `:root`).
2. Replace `{{ }}` placeholders — product name, headline, features, pricing tiers, email.
3. Drop your product screenshot into the `.mock` area. Deploy to any static host.
## Sections
Sticky nav · gradient hero + product mockup · 3-up features · 3-tier pricing · CTA band · footer.
